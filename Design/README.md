# 设计源文件

存放生成最终资产所需的源素材。成品（`App/GoTrans/Assets.xcassets/`）由这里的文件经脚本合成，
所以改配色、改留白或换分发形态时不需要重新找设计稿。

## `icon-artwork.webp`

App 图标的源图形：1254×1254、透明背景、两个气泡由一条缎带贯穿。

这是一张**标志**，不是可以直接使用的图标——它没有圆角方块造型、没有底色，而且内容横向顶到画布
边缘。圆角造型、底色、投影和各尺寸切图全部由脚本生成。

当前仓库中的图标由这条命令产出：

```bash
Scripts/finish-icon.swift Design/icon-artwork.webp /tmp/gotrans-1024.png \
    --bg '#0B0D14' --fit --inset 0.10
Scripts/make-icon.sh /tmp/gotrans-1024.png
```

`--fit` 是必须的：默认的 `--fill` 会居中裁切，而这张图的内容已经顶到右边缘，会被切掉一块。
`--bg` 也是必须的：源图背景透明，不铺底色的话圆角方块内部是空的，最终只能看到标志悬空，
图标造型不可见。

### 已知问题

在 16px 和 32px 下可辨识度偏弱。斜向构图、较细的缎带和大面积辉光在降采样后会糊成一片蓝白斑块，
要到 64px 才读得清楚。重做时应当追求：横向或居中构图而非斜向、更粗的图形笔画、更强的明暗对比、
更克制的辉光。

## 脚本

| 脚本 | 作用 |
| --- | --- |
| [`Scripts/finish-icon.swift`](../Scripts/finish-icon.swift) | 任意素材 → 1024×1024 母图（套 squircle、铺底色、加投影） |
| [`Scripts/make-icon.sh`](../Scripts/make-icon.sh) | 1024 母图 → 资产目录所需的 10 个尺寸 |

两个脚本的完整选项见各自文件头部的注释。
